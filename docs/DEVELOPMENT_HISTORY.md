# 键间 KeyMelody · v0.6.2（私密开发版）

纯 HTML / CSS / JavaScript 浏览器游戏弹琴练习器，无构建依赖，无第三方脚本或字体；采样文件与网站同源托管，按需加载。

## 运行与迁移

`dist/` 为完整静态网站。可以由任意静态服务器托管，也可打开 `dist/index.html` 进行本地体验（建议通过 localhost 使用，以获得稳定的浏览器存储行为）。未来可将该目录直接装入桌面 WebView；系统悬浮与全局输入属于独立的原生适配层。

## 第一版功能

- 三排 21 键、自定义英文字母键映射，内置合成钢琴音色。
- 字母谱、C 调文本数字谱、TXT 与本应用 JSON 导入导出、导入预览、基础文本编辑。
- 等待练习、节奏判定、演示播放；变速、节拍器、倒数、片段循环与跳转。
- 正确音符 / 错按 / 漏按统计，曲谱保存在当前浏览器 localStorage。
- 页面失焦或隐藏时暂停，未接入游戏、不发送模拟按键。

## v0.2 显示更新

## 文本记法

字母谱：`Q:1 W:0.5 [AS]:2 | _:1 E:1`

数字谱：`1:1 2:0.5 [135]:2 | 0:1 1':1 1,:1`

- 空格分开音符，方括号表示和弦。
- `:n` 指定拍数，缺省为用户选择的默认时值；`-` 为前一组延音。
- `_` 休止，数字谱还支持 `0` 休止。
- `|` 视觉分隔，暂不校验小节拍数；`#` 后至行尾为注释。
- 数字谱中 `1'` 高音、`1,` 低音，默认中音，暂不支持升降号、调号或图片中的附点/减时线。
- JSON 与其他导入类型见后续版本说明。
- 长条表示事件时值，练习只判起音，无长按判定。

## v0.3 导入、调试与浮窗

v0.3的默认目标为21个自然音、钢琴音色，C3—B5；所有文件在浏览器内读取。

- 文本：标准字母、连写社区字母、增强数字简谱、音名、唱名、Sky A1—C5位置谱、1—21顺序编号。
- 结构化：本应用v1/v2、未加密Sky Studio songNotes对象、含time/key或midi的notes数组、含beat/keys/duration的events数组、带表头的CSV/TSV。时间time为毫秒。
- MIDI：SMF0/1、PPQ制、运行状态、多轨、速度变化；忽略打击乐、踏板和弯音并提示。
- MusicXML：未压缩score-partwise，支持时值、和弦、声部、backup/forward及tie；不展开反复/跳转，不读取速度变化，并提示。
- Sky HTML：仅提取#ascii文本。扩展名.skysheet仅在内容匹配上述JSON结构时可读，不承诺全部原生或压缩Nightly格式。
- 文件上限2MB，最多20,000个事件。无完整节奏时标记等拍假设；半音/超音域默认报错，可显式近似、跳过或折回八度。
- 每类输入框有占位示例、规则及填入示例按钮。MIDI通过文件选择导入，显示转换后的毫秒时间谱。
- 导入框试听前30秒；保存后完整自动演奏、单步、前后跳转、修改当前组、循环和变速。调试不计练习成绩。
- 网页浮窗可拖动、边角缩放、调背景透明度；每行独立偏移、键间距和行距可保存；布局锁定避免误拖。
- Document PiP按能力检测提供；保留同一键盘和播放状态，使用PiP可见窗口驱动播放，关闭后收回并暂停。不提供桌面透明、鼠标穿透或游戏后台输入。

验证：`node check.cjs`、`node import-check.cjs`通过。实际浏览器逐项验证文本及MusicXML示例，保存、自动演奏推进、单组修改、浮窗、独立行拖动与布局保存。预览环境未提供Document PiP，因此该能力需在支持的正式浏览器验证；移动真机与游戏覆盖未测试。钢琴为本地合成音色，不是采样钢琴。

## v0.3.1 可选忽略未知内容

导入框新增“忽略未知字符 / 注释（本分类）”。默认严格校验，分类选择分别保存在浏览器；保存曲谱时记录其选项，重新载入时沿用。清理仅用于解析，不改写原始输入，预览报告忽略数量、片段和斜杠节奏限制。文本支持#、//和【…】注释；英文或数字恰好符合音符规则时不能自动判断为注释，需明确标记。

结构化格式保留原结构：JSON/CSV只清理键位文字及格式支持的注释，未知字段本就容许；MusicXML/HTML按支持的节点提取，不改写结构；MIDI不删除二进制字节。括号不配对、无效时值/时间、加密和不支持音高继续报错。忽略/不意味着识别分拍或补空拍。

验证：新增7类文本清理、中文/英文注释、模式关闭、精确JSON时间、结构错误与用户提供的斜杠谱回归；实际浏览器确认严格模式报错、开启后导入成功、忽略报告与分类独立记忆。


## v0.4 多琴盘与扫弦模拟

- 保留标准21键；新增15键Sky位置琴盘、21键吉他模拟和弦琴盘、自定义1—4行（最多26键）。15键使用固定C调参考音高C4—C6，游戏场景可能变调。
- 吉他Z—M暂设C、Dm、Em、F、G、Am、G7，尚未验证特定游戏的真实对应关系。每个和弦键算一次操作，可修改多个发声音高和0—100ms逐音间隔。音色为本地合成钢琴/吉他，可独立设置单音和和弦音量。
- 导入明确选择来源琴盘和目标琴盘，按音高转换；默认保留精确音高，无法演奏时报错。八度折回与整组精确匹配和弦需显式开启；音长不同的音不合并成一个和弦键。无完整时值的文本仍为等拍假设。
- 所有已有导入类型沿用；位置字母和编号按来源琴盘解释，音名/MIDI等按来源单音音域解释。和弦专用琴盘可先按单音来源导入后转换。支持仅练单音/和弦、当前琴盘测试、另存适配版。
- 大小、特效、键位、每行偏移和布局按琴盘分别保存。曲谱包含来源与目标琴盘快照；旧曲谱默认标准21键，自定义映射更新不会改写已保存曲谱的音高含义。导出的v2 JSON包含琴盘定义。
- 浏览器浮窗与Document PiP能力范围沿用v0.3，不提供游戏后台自动按键；自动演奏用于网站内调试。

验证：`node check.cjs`、`node import-check.cjs`、`node board-check.cjs`。浏览器验收15键、吉他扫弦单次计数、自定义四行/额外字母键、刷新恢复、源/目标导入与错误提示。未实测特定游戏的吉他映射、真实音色或游戏覆盖；Document PiP仍受浏览器支持限制。


## v0.5 CC0采样音色与时间轴拖动

- 新增6种采样音色：FreePats立式钢琴KW、尼龙弦古典吉他、卡林巴，以及VCSL英式羽管键琴、木琴、钟琴。均为CC0 1.0；保留原始作者说明、CC0文本、原文件URL和SHA-256于`dist/audio/`。音色来源和授权可在界面查看。
- 精选单力度／单次采样，转换为单声道32kHz MP3，截短至最多6秒、统一峰值并淡出尾部。保留Kalimba的SFZ微调，以实际科学音高校准VCSL的音名编号。采样间及原始音域外使用最近根音变调，不含原库的循环、松键、踏板及轮替层。
- 六包合计约3.4MB；选择音色后按需下载并显示进度，HTTPS环境尝试Cache Storage并使用浏览器HTTP缓存。最多保留两包解码音色，加载失败明确切换到合成钢琴。默认新琴盘使用采样钢琴／采样吉他，已保存的音色选择继续沿用。
- 试听按钮用同一段C大调旋律比较；单步、导入试听、完整演示和和弦扫弦共用采样播放。原合成钢琴／吉他仍可选择，单音、和弦音量可分别静音。
- 时间轴支持鼠标／触屏水平拖动；固定光标下移动音符，松手定位到音符组起点并暂停。点击音符可跳转；方向键逐组，Shift+方向键每次4组，Home/End到片段首尾。遵守循环范围，拖动清除本轮统计，点击播放从所选组继续。
- `scripts/prepare-audio.py`记录采样加工步骤（维护工具，依赖Python/numpy和ffmpeg；从原库解压目录读取，不参与网站运行）。

验证：`node check.cjs`（新增拖动、循环边界和指针取消）、`node audio-check.cjs`（资源、加载去重/进度、调音、零音量、释放、内存限制、失败重试）、`node import-check.cjs`、`node board-check.cjs`通过。浏览器验证6种采样解码/试听、来源说明、鼠标拖动首尾定位与所选组播放。未进行真实手机触摸验收；声音主观质量仍需用户试听反馈。

## v0.6.0 琴盘、设置与节奏练习

- 项目简介：键间 KeyMelody 是面向游戏弹琴爱好者的网页练习工具，支持多种琴盘、琴谱导入、动态按键提示、等待练习、节奏练习和自动演奏，帮助使用者熟悉键位、检查曲谱并练习节奏。
- 吉他直接使用第一行Q/W/E/R/T/Y/U扫弦，对应C/Dm/Em/F/G/Am/G7，第二行中音、第三行低音；不提供旧版转换功能。琴盘测试覆盖全部按键。仍为模拟扫弦，音色独立选择。
- 左侧固定“设置”，窄屏保留图标与文字。四类设置：琴键与显示、布局与浮窗、练习与判定、声音与延迟；键位映射单独保存，其余即时保存。
- 节奏判定为宽/中/严，Perfect/Good/Bad最大绝对偏差分别80/150/230、50/100/160、30/65/110 ms；到期未命中为Lost。Early/Late按补偿后的有符号偏差展示。等待模式不套用节奏等级，自动演奏不计分。
- 准确率逐键加权，Perfect=1、Good=.7、Bad=.3、Lost=0，错按以0加入分母；免判键不计分。Perfect/Good整组延续连击，Bad/Lost和错按中断，整组取实际判定最差等级。开启两键通过时，其余键免判，补按免判键不额外加分或扣分。重复按住不重复计分，同一键的密集音符择最近未判事件。
- 全局保存档位和-300至+300 ms补偿，切换琴盘沿用。换档位、修改补偿或重置统计回到片段开头，避免重置后把已演奏音符再记为漏按。
- 自动校准独立播放120 BPM节拍：一轮四拍示范后进行四轮，每轮第三拍按空格或点击，固定同一种输入；音频按AudioContext时钟提前排程、输入按单调时钟记录，四次取中位数。每次需在第三拍±300 ms内且最大差异≤80 ms；失败保留旧值。重复点击不重复采样，关闭/失焦/隐藏/声音中断取消。成功自动应用，可手调/归零。
- 本轮未加入打赏，也未更新腾讯云公开发布包。

验证：node check.cjs、node rhythm-check.cjs、node board-check.cjs、node import-check.cjs、node audio-check.cjs。单元与模拟传输覆盖判定边界、补偿正负方向、密集重复音、和弦最差等级/连击、免判、四次校准成功/失败与旧值保留；浏览器验收设置入口、吉他扫弦单次计数、节奏实时Perfect判定、校准漏点保护、四轮空格采样自动应用（+10 ms，四次差异6 ms）、档位/兼容选项/手调补偿刷新恢复。设备实际听感与移动端真机需实测。
