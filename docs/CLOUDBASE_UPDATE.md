# 键间 v0.6.2 公开网页更新说明

## 下载哪个文件

- 腾讯云部署：keymelody-v0.6.2-cloudbase.zip。
- GitHub源码：keymelody-v0.6.2-source.zip。

cloudbase.zip根目录直接是index.html。source.zip包含dist目录和开发文档，不要把源码ZIP直接作为静态部署包上传。

## 更新腾讯云上现有网站

1. 保留旧版部署包或控制台的上一条成功部署记录，方便回退。
2. 进入CloudBase的keymelody-public环境 → 静态网站托管 → 现有KeyMelody应用。
3. 在该应用内选择更新部署/上传代码一类入口，上传keymelody-v0.6.2-cloudbase.zip。使用现有应用，沿用已配置的域名和路由。
4. 如果再次出现构建配置，按下表填写；部署路径必须与现有网站保持一致。

| 配置项 | 值 |
| --- | --- |
| 框架 | 其他 |
| 目标目录 | ./ |
| 安装命令 | 留空 |
| 构建命令 | 留空 |
| 构建产物目录 | ./ |
| 部署路径 | 沿用原值；网站原来在根路径则为/ |
| 环境变量 | 不需要新增 |

如果使用“文件管理”入口：解压cloudbase.zip，将全部文件和audio子目录覆盖上传到原部署位置，首页仍为index.html；推荐先上传脚本、样式与音色，最后更新index.html。不要额外套dist或版本名文件夹。请确认旧资源没有漏传，不要只上传首页。

5. 等待部署成功后打开原网址。若控制台提供刷新缓存功能，按需刷新；浏览器可使用Ctrl+F5或无痕窗口检查。
6. 核对左侧版本为“公开版 · v0.6.2”。
7. 打开设置，确认第五栏为“打赏支持”；检查第一排吉他扫弦、节奏判定和延迟校准。
8. 在页面顶部确认右下角出现开始按钮，点击后黑色区域上沿对齐窗口；切换节奏练习，确认判定浮层不遮挡音符。
9. 试听一种真实采样，确认audio目录上传完整。重要曲谱更新前可先导出备份。

## GitHub更新（可选）

解压source.zip，将keymelody-v0.6.2-source文件夹内部内容上传到源码仓库，保留dist/docs/scripts目录结构。提交消息可填“发布键间公开版 v0.6.2”。创建Release时标签用v0.6.2，发布说明可直接使用RELEASE_NOTES.md，附加专用cloudbase.zip供下载。

源码包不包含Sites托管配置、凭据或个人曲谱。私密开发网站与腾讯云公开网站分别发布，后续私密开发更新不会自动覆盖这个公开版本。这里交付的是发布文件，腾讯云更新需由你在控制台完成。
