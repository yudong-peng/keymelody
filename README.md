# 键间 KeyMelody · 公开版 v0.5.0

一个纯 HTML / CSS / JavaScript 游戏弹琴练习网站。无需后端、数据库、构建或第三方 CDN，网页及音色可整体部署至静态托管。

## 本次公开版本

当前快照来自私密开发版 v0.5，导出日期为 2026-10-20。公开页面的版本标识为 v0.5.0。GPT私密开发版继续独立迭代；本仓库与CloudBase只在选定公开版本后更新，不自动跟随开发版。

- 标准21键、15键Sky位置琴盘、21键吉他模拟和弦、自定义1—4行琴盘。
- 圆形单音键、可调大小与提示效果；吉他和弦键按一次计一次操作。
- 字母、社区连写、数字简谱、音名、唱名、Sky位置、顺序编号、JSON、CSV/TSV、MIDI、未压缩MusicXML等导入；各分类可选忽略未知字符。
- 等待练习、节奏练习、自动演奏／调试、变速、片段循环、单步试听和音符组编辑。
- 六种CC0真实采样音色：立式钢琴、古典吉他、卡林巴、羽管键琴、木琴、钟琴；另保留合成钢琴和吉他。
- 时间轴可左右拖动定位；网页内浮动键盘支持缩放、每行独立偏移。

## 本地运行

推荐通过HTTP服务访问，直接双击HTML可能导致采样文件加载受浏览器限制。安装Python 3后，在项目根目录运行：

```bash
python -m http.server 8000 --directory dist
```

然后打开 http://localhost:8000/ 。命令窗口关闭后服务结束。

## 回归检查

安装Node.js 18或以上版本后，在项目根目录运行 `npm test`；不需要先执行npm install。Node.js只用于这些检查，部署后的网站不依赖Node服务。

## CloudBase部署

无需构建。将 `dist/` 内部的文件和子目录上传到静态网站托管根目录，默认首页设置为 `index.html`。使用单独的CloudBase部署ZIP时，其ZIP根目录已经包含首页。

首次推荐手动发布。GitHub仓库可以保持私有，公开网站与源码仓库的可见性分别管理；暂不关联自动部署分支。请参考操作指南配置自定义域名和HTTPS。

## 数据与功能边界

用户导入曲谱、自定义琴盘、键位和布局保存在当前浏览器中，不会自动上传到服务器。换域名或设备不会自动同步；重要曲谱请使用导出功能备份。本包不含个人曲谱或浏览器设置。

吉他预设为模拟和弦，尚未针对特定游戏验证Z—M映射。自动演奏只在网页内发声，不向游戏发送按键。置顶小窗依赖Document PiP支持，不提供桌面透明或鼠标穿透。图片/PDF、压缩或加密乐谱不在当前导入支持范围。

采样为精选网页版本，不含原音色库完整的力度层、轮替、松键和踏板表现。真实手机触摸、游戏覆盖及所有浏览器的PiP能力尚未完成实测。
